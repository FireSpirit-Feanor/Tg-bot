# BookBot — Консольный бот-помощник по книгам

## Описание

Консольное приложение, имитирующее работу бота для поиска и подбора книг.  
Программа реализована с использованием принципов объектно-ориентированного программирования (ООП) и паттерна подменяемых обработчиков через интерфейсы.

---

## Как запустить

1. Откройте проект в **Eclipse IDE**
2. Найдите файл `BookBot.java` в пакете `src`
3. Нажмите правой кнопкой мыши → **Run As → Java Application**
4. Бот запустится в консоли Eclipse

---

## Команды бота

### Главное меню

| Команда | Описание |
|---------|----------|
| `1` | Перейти в раздел **Жанры** |
| `2` | Перейти в раздел **Лучшие книги** |
| `3` | Перейти в раздел **Поиск по названию** |
| `0` | Выйти из бота |

---

### Раздел "Жанры" (команда `1`)

После выбора главного меню `1` откроется список жанров:

| Команда | Описание |
|---------|----------|
| `1` | Фантастика |
| `2` | Детектив |
| `3` | Роман |
| `4` | Фэнтези |
| `0` | Вернуться в главное меню |

---

### Раздел "Лучшие книги" (команда `2`)

Показывает топ книг по рейтингу.  
Для возврата в главное меню введите `0`.

---

### Раздел "Поиск по названию" (команда `3`)

1. Введите название книги (например: `Война и мир`)
2. Бот выполнит поиск и выведет результат
3. Для возврата в главное меню введите `0`
